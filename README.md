## ⚡ Getting Started

### Prerequisites
- Node.js 18+
- npm

### 📦 Installation

```bash
git clone git@github.com:Nithish-Bharathwaj-N/portfolio.git
cd portfolio
npm install
```

### 🖥️ Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 🏗️ Build

```bash
npm run build
npm run start
```

### ✅ Type Checking & Linting

```bash
npm run typecheck
npm run lint
```

## ✏️ Editing Content

All portfolio content — profile info, skills, projects, experience, education, certifications, achievements, and social links — lives in a **single file**: `lib/portfolio-data.ts`. Update the relevant exported array/object and the corresponding section re-renders automatically.

To add a project screenshot: drop the image into `public/images/` and set the `image` field on that project's entry in `lib/portfolio-data.ts`.

## ☁️ Deployment

This project is configured for **Netlify** via `netlify.toml` and `@netlify/plugin-nextjs`. Connect the repo to Netlify and it will build and deploy automatically on every push to `main`.
